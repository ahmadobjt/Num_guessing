Number Guessing Game
A simple command-line number guessing game built with Python.

Choose a difficulty level, try to guess the secret number, and use the hints to find the correct answer before your attempts run out.

Difficulty Modes
Mode| Number Range| Attempts
Kids| 1 – 50| 20
Easy| 1 – 100| 15
Medium| 1 – 150| 10
Hard| 1 – 200| 8

What It Includes
- Four difficulty levels
- Randomly generated secret number
- High/low hints after each guess
- Limited attempts for each mode
- Input validation
- Win and lose results

🛠 Built With
Python

The project uses Python's "random" module to generate the secret number.

Learning Purpose
This project was created to practice:

- "if / elif / else"
- "while" loops
- User input
- Exception handling
- Random number generation
- Basic game logic
